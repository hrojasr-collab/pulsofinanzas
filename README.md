## Descripción del Proyecto
Pulso Finanzas es una Single Page Application (SPA) desarrollada con React, TypeScript y Vite que permite organizar movimientos financieros (ingresos y gastos), diferenciar entre el ámbito personal y de microemprendimiento, monitorear límites de presupuesto mensual y simular movimientos planificados a futuro.

## Requisitos Previos
- Node.js (versión 18 o superior)
- npm
